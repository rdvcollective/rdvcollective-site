RENDEZVOUS COLLECTIVE — STANDALONE STATIC SITE

Open index.html directly in a modern browser. No server, package manager, or
build step is needed.

The top level contains:
- index.html
- styles.css
- script.js
- images/ and fonts/ with the local image, logo, icon, and font assets

All referenced assets use relative paths and are included in this folder.
The ZIP can be extracted as-is, or the folder itself can be moved to a static
host. Keep the folder structure intact.

The inquiry form is intentionally non-sending: it does not store or transmit
messages because no receiving inbox has been configured.

DM Sans and Playfair Display font files are included under their Open Font
License notices in fonts/.
